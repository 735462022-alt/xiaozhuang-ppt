# 小壮ppt

小壮ppt 是一个按「主题 + 模板编号」制作演示文稿的 Skill。包内带有 T01–T10 共 10 套视觉模板和示例，默认制作 10 页 16:9 演示文稿，交付主要文字可编辑的 PPTX 和 4K 竖向全览图。

## 下载与使用

- [下载小壮ppt.skill](./小壮ppt.skill)：与上传前的原始技能包内容一致，仅更改文件名。
- [查看 SKILL.md](./reference-to-ppt/SKILL.md) 和 [模板总览](./reference-to-ppt/assets/template-overview.jpg)。
- 如需本地安装，可将完整的 reference-to-ppt 文件夹放进对应应用的用户技能目录。包内技能 ID 保持为 reference-to-ppt。制作成品需要宿主提供演示文稿制作能力，部分场景需要图像生成能力。
- 调用示例：使用 reference-to-ppt，主题：城市周末散步指南；模板：T09。
