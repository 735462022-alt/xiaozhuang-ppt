# 审美PPT

用户操作只有两项：**主题 + 模板编号**。选完直接制作完整成品，不增加大纲、受众、配色、字体、页数、配图来源或审批问卷。用户已经提供的内容不再询问。默认10页16:9横版，输出每页3840×2160，竖向依次排列。明确的新要求优先于默认值。

## 首次回复与输入选择

首次响应优先：主题或模板尚未齐全时，直接用本技能已加载的下方模板表回复，不等待读catalog、读取图片、打开预览网页、检查运行库、检索资料或调用生成工具。预览是可选补充，不能成为用户了解选项的唯一入口。不要先用一轮“正在打开模板”替代主题提问和模板展示。

- 两项都缺：同一条用户可见回复内，询问“这次PPT的主题是什么？”，并主动列出下方全部10个模板的编号、名称及一句风格，让用户直接选；附可选预览链接和一次回复示例“主题：……；模板：T09”。不只给链接或只举一个编号。
- 已有主题、缺模板：不重问主题，直接列10款模板供选。
- 已有模板、缺主题：只询问主题，不重复展示整份模板目录。
- 两项都有：立即制作，不再展示选型或等用户确认大纲。
- 用户说“你选”：主题已有则按主题选模板并继续；没有主题只问主题。
- 用户只说“帮我做个PPT”不构成主题，不擅自沿用上次作品的主题。

模板预览：[10款详细预览](assets/模板预览.html)；[总览图](assets/template-overview.jpg)从左到右、从上到下对应T01至T10。先完成上述文本交互；仅在用户要看图、请求打开预览或图片能直接随回复展示时再加载，不默认自动打开外部窗口。

用户可一次回复“主题＋模板”，也接受唯一可识别的模板名称。request_user_input_async可作为补充，但不能取代回复中可见的模板清单，不把预选值当作用户答复。

允许用户事先附文案、数据、案例偏好或明确页数，但都不是必填项。不要求用户上传参考图，模板已内置。用户明确要求自带新参考/第11款时再按新方向处理，不悄悄增加模板数量。

## 执行

1. 使用当前可用的 Presentations 技能完成原生PPT制作及最终检查，使用 load_workspace_dependencies 获取本机工具库；按需使用 imagegen 技能生成主题图像。缺少这些能力时先说明具体缺项，不声称已生成PPT或用一张图冒充原文件。不得为了安装不明工具让用户多填产品参数。
2. 内部完成10页内容结构和所选模板的设计提取，给一条简短进度说明后继续，不把“设计规范/大纲已完成”当作成品交付。内容随主题组织，默认不让全部页面套同一标题加列表。
3. 先抓住参考的字形、材质、图像画风、图文层次、密度和阅读节奏，再改为新主题。大胆错位、不对称、跨幅大字与有意叠压按模板气质使用。不要过度简化为通用色块、普通卡片或粗糙图案。T08等克制模板仍保留留白，不强行杂乱。
4. 按 [制作与交付细则](references/production.md) 准备配图和可编辑内容。关键标题、正文、数据和流程语义使用原生文字、表格、图表/图形；不把整页烤成位图。艺术字、摄影、纹理和装饰可以是位图，要区分可编辑范围。
5. 按主题需要核验时效事实。用户要求真实人物/case/X/YouTube时查原始发布、访谈或官方材料，注明来源与日期；不要编造数字和引语。假设例子在对应页明确标注。只补与主题有关的研究，不默认每套都要AI创始人或商业收入案例。
6. 先完成并最终检查PPTX，再重新导入最终文件导出各页4K PNG，逐页查看。用 [打包脚本说明](references/packaging.md) 拼接长图并核验原生文字。脚本校验不替代逐页视觉检查。不要跳过原生表格/字体检查或为赶进度交付未检查文件。

## 制作速度

输入齐全后再加载所选模板的catalog记录、profile和必要示例，不读取其余9套的详细素材。已读取的模板与规范在同一任务中复用，不反复检查同一文件。

- 复用干净的纸纹、装饰与已验证版式思路，不能把带旧主题文字的样张直接拿来当新背景。无需重新做无变化的纯装饰。
- 一次整理全套内容与文字避让区，再批量准备独立配图。工具支持并发时合并独立调用，不反复逐页等待和试探；依赖、修订与最终导出仍顺序执行。不默认启用子代理。
- 使用内置imagegen返回结果时只保存素材路径与短元数据，不将完整base64打印到工具日志。生成的原图复制到任务目录后继续排版。
- 当前事实按主题必要范围查询原始来源，已查证资料在本任务复用。默认不研究与主题无关的人物、收入或案例。
- 先检查最终候选版的逐页预览并修正，再导出一次全套4K和长图；没有新问题不重复生成或重跑全套。可编辑性与视觉检查不能为提速省略。
- 进度更新只说已完成与下一步，不以长篇计划延迟用户选择。首条交互快，不等于承诺全套生成固定几秒完成。

## 默认交付

最终回复先给这两个文件，每个都提供真实可打开的完整路径，沿用 Presentations 的文件引用格式：

1. **4K竖向全览PNG**：宽3840，N页高 `2160*N + 96*(N-1)`，10页为3840×22464。它是10张横页的竖向罗列，不是把PPT页改成竖版。
2. **PPTX原文件**：N张独立页面，主要文字可直接编辑，页面可在PowerPoint中拖动重排。不能用只含一张长图的PPT替代。

同时保留4K单页ZIP、设计规范与来源HTML，放在同一输出目录，便于用户需要时取用。来源HTML包含完整配图提示词、素材依据、字体近似说明和可编辑范围，避免把制作说明塞进观众正文。4K是输出尺寸，不承诺较低分辨率背景含有原生4K细节。字体未嵌入时说明跨设备可能替换。

持续记下实际文件状态。如果用户问“好了吗”，检查文件和当前工作再回答，不把设计稿、背景图或运行中的导出说成已完成。不中途漏交后切换到下一个主题。
